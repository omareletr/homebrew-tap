# Rūznāma for Homebrew

[Rūznāma](https://ruznama.app) is a daily journal for your to-dos, for iPhone and Mac. The Mac app is in beta.

```bash
brew install --cask omareletr/tap/ruznama
```

`brew upgrade --cask ruznama` takes you to the newest beta. The same build is on the [latest release](https://github.com/omareletr/homebrew-tap/releases/latest) as a `.dmg`, signed with Developer ID and notarised by Apple. It needs macOS 26.

Questions or problems: support@ruznama.app.
